# 코치 마켓 · 결제 오픈 가이드

현재 상태: 기능은 전부 구현·배포돼 있고 **이중 게이트로 잠김**.
프로덕션 앱에는 "준비 중입니다" 티저만 노출된다.

## 1. 오픈 스위치 (열려면 이것만 하면 됨)

| 스위치 | 위치 | 하는 일 |
|---|---|---|
| `EXPO_PUBLIC_COACH_MARKET=1` | 앱 **빌드 시** env (eas build) | 코치 탭·구인구직·이력서·오퍼레터 노출 |
| `EXPO_PUBLIC_PAYMENTS=1` | 앱 **빌드 시** env | 결제 수단·결제 버튼·정산 화면 노출 |
| `PAYMENTS_MOCK=1` | **Pi 서버** env (`packages/server/.env`) → 서버 재시작 | 결제 API 게이트 해제 (현재 Mock PG) |

- 클라 스위치는 빌드 타임이라 **스토어 재배포 필요** (웹은 Deploy Web 재실행).
- 서버 스위치는 Pi 의 .env 수정 + pm2/도커 재시작.
- 코치 마켓만 먼저 열고 결제는 나중에 여는 것도 가능(스위치 독립).

## 2. 결제를 "실돈"으로 열기 전 필요한 것

지금 결제는 **Mock PG** — 카드 등록·청구·정산이 전부 모의 동작.
실제 돈이 오가려면 아래가 선행돼야 한다:

1. **사업자등록** (개인사업자로 시작 가능)
2. **PG 계약** — 둘 중 하나:
   - **토스페이먼츠**: 빌링(정기결제) + 지급대행(코치 정산 이체) 모두 제공. 심사 1~2주.
     레슨비처럼 "플랫폼이 받고 코치에게 분배"하는 구조는 **지급대행 상품** 필수(전자금융거래법).
   - **포트원(구 아임포트)**: 여러 PG 래핑 + 파트너 정산 기능. 초기 무료 티어 있음.
3. **연동 작업** (계약 후 1~2주 예상):
   - `packages/server/src/modules/payment/provider.ts` 의 MockProvider 를
     실제 PG 구현체로 교체 — **이 파일 하나가 교체 지점 전부** (빌링키 발급/청구/취소)
   - 코치 지급을 mock 이체 → 지급대행 API 호출로 교체 (`payment.service.ts` 의 executePayout 주석 지점)
   - 웹훅(결제 실패·취소 통지) 수신 라우트 추가
4. **수수료 정책 확정** — 현재 `PLATFORM_FEE_RATE` env, 기본 10%.

참고: 오프라인 레슨 서비스라 **앱스토어 인앱결제(30%) 대상 아님** — 카드 PG 로 결제해도 심사 통과 가능.

## 3. 권장 오픈 순서

1. **코치 마켓만 오픈** (`EXPO_PUBLIC_COACH_MARKET=1` 로 1.0.4 빌드) — 결제 없이 구인·구직·채팅·오퍼레터까지 다 돌아감. 코치·클럽 풀부터 모은다.
2. 사업자등록 + PG 계약 진행 (기다리는 동안 1번이 돌아감)
3. PG 연동 교체 → 스테이징(로컬)에서 토스 테스트 키로 검증
4. **결제 오픈** (`EXPO_PUBLIC_PAYMENTS=1` 재빌드 + 서버 게이트 교체)

## 4. 오픈 전 체크리스트

- [ ] 1.0.4 빌드에 코치 탭 포함 여부 결정 (현재 스토어 1.0.3 은 티저)
- [ ] 코치 이용약관·수수료 고지 문구 (결제 오픈 시 필수)
- [ ] PLATFORM_FEE_RATE 확정 (현재 10%)
- [ ] 코치 온보딩 안내 (프로필·이력서 작성 가이드 — 인스타 카드로 홍보 가능)
