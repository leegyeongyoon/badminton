# 콕고 인스타그램 카드 템플릿

실제 앱 화면을 iframe 으로 라이브 임베드해 캡처하는 방식.

재생성 방법:
1. 로컬에서 Expo web(8081) + API 서버 실행, 브라우저에서 운영자 계정 로그인
2. 이 폴더의 html/css 를 `packages/mobile/public/` 에 복사 (public 은 커밋 금지 — 프로덕션 웹에 노출됨)
3. `http://localhost:8081/ig1.html` … 열고 스크린샷 → 중앙 크롭(592x740) → 1080x1350 리사이즈
4. 문구는 각 html 의 .eyebrow / .headline 만 수정하면 됨

주의: 미공개 기능(코치 구인·구직, 결제)은 카드에 노출 금지 — ig3 는 스크립트로 숨김 처리함.
