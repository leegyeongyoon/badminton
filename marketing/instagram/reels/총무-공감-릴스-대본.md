# 총무 공감 릴스 — 대본 3종

원칙: 기능 소개 ❌, 공감 먼저 ⭕. 총무·반장이 "이거 완전 난데?" 하고 저장/공유하게 만드는 것이 목표.
길이 15~20초, 자막 크게, 마지막 1컷에만 콕고. 배경음은 유행 밈 사운드.

---

## 1편 — "정모 끝나고 총무" (손실 회피 각)

| 컷 | 화면 | 자막 |
|---|---|---|
| 1 (3s) | 정모 끝나고 다들 웃으며 인사하는 장면 | 정모 끝. 다들 집에 갈 때… |
| 2 (4s) | 혼자 폰 켜고 은행앱+엑셀+단톡 번갈아 보는 손 | 총무는 지금부터 출근 |
| 3 (4s) | 입금내역 스크롤 무한 반복 (당황 표정) | "김철수… 김철수가 두 명인데?" |
| 4 (3s) | 단톡 캡처풍: "저 지난주에 냈는데요?" | 제일 무서운 다섯 글자 → "저 냈는데요?" |
| 5 (4s) | 콕고 납부 현황판 화면 (확인✓ 줄줄이) | 회비 시비, 이제 안 생겨요 — 콕고 |

캡션: 총무님들 이거 보고 심장 아프면 좋아요… 회비·레슨비 계산·청구·추적은 콕고가 해요. 돈은 원래 계좌 그대로. #배드민턴 #배드민턴동호회 #총무 #배드민턴클럽 #콕고

## 2편 — "레슨반장의 1일" (반장 각)

| 컷 | 화면 | 자막 |
|---|---|---|
| 1 (3s) | 카톡 보내는 손 | 1일: "이번 달 레슨비 입금 부탁드려요~" |
| 2 (3s) | 같은 화면 반복 | 5일: "입금 부탁드려요~^^" |
| 3 (3s) | 같은 화면, 이모티콘만 늘어남 | 12일: "부탁드려요…🙏🙏🙏" |
| 4 (3s) | 한숨 쉬는 얼굴 | 반장은 빚쟁이가 아닙니다 |
| 5 (5s) | 콕고 납부 링크 화면 → 자동 체크되는 모습 | 링크 하나 보내면 끝 — 독촉은 콕고가 |

캡션: 레슨반장님 대신 독촉해드립니다. 수강생은 앱 설치도 필요 없어요. #배드민턴레슨 #레슨반장 #배드민턴코치 #콕고

## 3편 — "이번 달의 나" (회원 과시 각 — 기록 카드 출시 연계)

| 컷 | 화면 | 자막 |
|---|---|---|
| 1 (4s) | 헬스인들 오운완 인증 밈 화면 | 헬스인: 오운완 인증 |
| 2 (4s) | 러너 기록 공유 화면풍 | 러너: 10km 인증 |
| 3 (4s) | 배드민턴 치는 본인 영상 | 배드민턴인: …인증할 게 없다? |
| 4 (5s) | 콕고 "9월의 나 — 출석 8일 · 게임 21판 · 누적 132판" 카드 | 이제 있음. 콕고 '이번 달의 나' |

캡션: 이번 달 몇 판 치셨어요? 내현황에서 '자랑하기' 눌러보세요 🏸 #배드민턴스타그램 #오운완 #배드민턴기록 #콕고
